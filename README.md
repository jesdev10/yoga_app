# Bliss Mind

A wellness platform that makes it easy for customers to discover and book wellness sessions.

## About the Project

Bliss Mind is a wellness platform designed to connect customers with wellness services such as:

- Yoga
- Pilates
- Meditation
- Ice Bath Sessions

The platform allows customers to view available sessions, make bookings, and receive confirmation after a successful booking.

It also provides a portal for instructors to submit their CVs.

## Key Features

- Browse available wellness sessions
- Book wellness sessions
- Booking confirmation notifications
- Yoga, Pilates, Meditation and Ice Bath sessions
- Session duration management
- Instructor CV submission
- Daily wellness articles
- Flexible payment options

## Target Users

- Customers
- Wellness Instructors
- Administrators
